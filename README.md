# Moni7

> Offline-first Personal Finance Tracker built with Nuxt.

---

## Overview

Moni7 is a mobile-first Progressive Web App (PWA) for personal finance management inspired by the clean and modern UI of the Moni application.

The application is designed to work completely offline using the browser's native IndexedDB without relying on cloud services or native Android wrappers.

Moni7 is also designed with AI-assisted development in mind. The project architecture, coding standards, and engineering decisions are documented to ensure consistent results when using AI coding assistants.
